## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-platform-targets`
- `allow-configure-platform-target`
- `allow-preview-platform-meeting`
- `allow-send-platform-meeting`
- `allow-list-webhooks`
- `allow-create-webhook`
- `allow-delete-webhook`
- `allow-set-webhook-active`
- `allow-test-webhook`
- `allow-dispatch-event`
- `allow-export-meeting-markdown`
- `allow-prepare-drive-markdown`
- `allow-get-cloud-snapshot`
- `allow-list-cloud-snapshot-ids`
